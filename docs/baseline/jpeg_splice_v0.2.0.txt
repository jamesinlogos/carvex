JPEG splice acceptance baseline (H-18 step 0 / conflict C1)
=========================================================

Protocol: harness.md §6.2 H-18(0). The script
`scripts/jpeg_splice_property.py` generated 50 distinct images per content
class (noise, gradient+noise, photo-like from `bench/corpus/jpeg`), saved each
as baseline and progressive JPEG, and evaluated 1,000 independent pairs with
cuts aligned to 512 or 4096 bytes inside 10-90% of the shorter file. A splice
counts as accepted when an emitted output has `validation=decoded` and a
SHA-256 that matches neither input. Wilson intervals are 95%.
